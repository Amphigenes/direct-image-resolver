# Direct Image Resolver ( AKA direct-image-resolver)
MS Edge extension that redirects lmag3Twi5t, Pixh0st and lmag3V3nu3 to the direct image. 

## Supported hosts
- ImageTwist
- Pixhost
- ImageVenue

## How it works
When opening a supported image host URL, the extension automatically redirects
to the clean image file, skipping ads and scripts.

## Installation (manual)
1. Download or clone this repository
2. Open `chrome://extensions`
3. Enable **Developer mode**
4. Click **Load unpacked**
5. Select the extension folder
